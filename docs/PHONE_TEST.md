# 첫 폰 테스트

USB 연결 없이 APK를 폰에서 내려받아 설치합니다. 앱 이름은 **하루 조각**입니다.

## 스티커 한 개 만들기
1. 인터넷에 연결한 상태에서 앱의 **첫 스티커 만들기**를 누릅니다.
2. 배경과 잘 구분되는 컵이나 물건 사진을 선택합니다.
3. **자동으로 오려내기**를 누릅니다. 최초 사용에는 모델 준비가 필요해 재시도가 필요할 수 있습니다.
4. 체크무늬 미리보기에서 물건이 온전히 남고 배경이 투명한지 확인합니다.
5. 이름과 촬영 날짜를 입력하고 저장합니다. 촬영 날짜 정보가 있으면 자동으로 채워지며 수정할 수 있습니다.
6. 보드에서 스티커를 누르고 확대 이미지 아래에 이름·날짜가 맞게 나오는지 확인합니다.

## 일기 만들고 다시 열기
1. 스티커 상세에서 **일기에 붙이기 → 새 일기 쓰기**를 누릅니다.
2. **글 쓰기**에서 한글과 줄바꿈을 입력한 뒤 **글 입력 완료**를 누릅니다.
3. **스티커 붙이기**로 같은 스티커를 한 번 더 추가합니다.
4. 각각 끌어 옮기고, 누른 뒤 아래 크기·회전 슬라이더를 조절합니다.
5. 저장하고 일기장 탭에서 다시 엽니다.
6. 앱을 완전히 종료했다 다시 열어 글·위치·크기·각도가 유지되는지 확인합니다.
7. 스티커함에서 스티커를 삭제한 뒤 기존 일기를 열어 이미지가 남아 있는지 확인합니다.

## 확인할 결과
- 배경 제거: 사용 가능 / 수정 필요 / 사용 불가.
- 세로·가로 사진의 방향과 투명도.
- 사진 선택 취소, 권한 거절, 촬영 취소 후 앱이 계속 동작하는지.
- 글 입력 중 스티커가 움직이지 않는지.
- 보드의 이동·확대·누르기와 일기 편집이 손가락으로 편한지.

문제가 생기면 사용한 화면, 누른 버튼, 표시된 안내와 함께 알려주세요. 배경 제거 결과는 가능하면 컵·음식·인형·복잡한 배경·털이 있는 대상 각각 확인합니다.

자동 배경 제거가 실패하면 다른 사진을 선택하거나 **사진 그대로 사용**으로 나머지 흐름을 시험할 수 있습니다. 이 경우 배경 제거 목표는 미완료로 기록합니다.

현재 백업 기능은 없습니다. 테스트 중에는 중요한 기록을 유일한 사본으로 보관하지 마세요. 기록을 확인하기 위해 앱을 지우거나 재설치할 필요는 없습니다.
