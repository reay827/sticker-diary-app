# PC 가상폰 테스트

이 PC용 Android 가상폰과 x64 앱 빌드를 준비했습니다. Android Studio를 따로 열 필요는 없습니다. 실제 폰과 가상폰의 기록은 서로 별개입니다.

## 처음 한 번
현재 PC는 BIOS 가상화를 지원하고 켜져 있지만 Windows의 가상폰 가속 기능이 준비되지 않았습니다.

1. Windows에서 `Win + R`을 누르고 `optionalfeatures`를 입력해 실행합니다.
2. **Windows 하이퍼바이저 플랫폼**을 체크합니다. 다른 항목은 바꿀 필요 없습니다.
3. 확인을 누르고 설치가 끝나면 PC를 다시 시작합니다.
4. 프로젝트 폴더의 **PC테스트-시작.cmd**를 더블클릭합니다.

실행 버튼은 Windows 설정을 자동 변경하거나 PC를 자동 재부팅하지 않습니다. 기능이 꺼져 있으면 안내 후 설정 목록을 열지 물어봅니다.

## 앱 사용
- **PC테스트-시작.cmd**: 가상폰 시작 → 앱 설치 또는 업데이트 → 하루 조각 열기.
- **PC테스트-사진추가.cmd**: PC에서 고른 사진을 가상폰 사진함에 복사 → 앱 열기.
- 앱에서 **첫 스티커 만들기 → 사진 선택**을 누릅니다.
- 처음 배경을 제거할 때는 인터넷에 연결합니다. 가상폰 Google Play 서비스에서 모델을 준비해야 합니다. 가상폰의 배경 제거 호환성은 아직 검증하지 않았습니다.
- 한 손가락 이동은 마우스로 끌면 됩니다. 스티커를 선택하면 크기·회전 슬라이더가 나옵니다.
- 종료할 때 가상폰 창을 닫습니다. 다음 실행에도 저장한 기록이 유지됩니다. 앱을 삭제하거나 가상폰 데이터를 초기화하지 마세요.

첫 연결에서 가상폰에 **Allow USB debugging?**이 나오면 **Always allow from this computer**를 체크하고 **Allow**를 누릅니다. PC와 가상폰의 개발 연결을 승인하는 화면이며 실제 USB 케이블은 필요 없습니다.

이 PC에서는 Windows 가속 기능 활성화·재부팅·연결 승인 후 가상폰 부팅과 **하루 조각 첫 화면 표시**까지 확인했습니다. 배경 제거는 테스트 사진으로 별도 확인해야 합니다. 실행이 막히면 표시된 안내를 채팅에 알려주세요.

## 개발 설정
도구: 프로젝트 상위 `.devtools/android-sdk`, 가상폰 저장: `.devtools/avd`, 이름 `haru_pc`, 전용 연결 포트 `5580`. Android 15(API 35) Google Play x86_64 시스템을 사용합니다. 로컬 APK는 `build/pc/haru-jogak-pc.apk`이며 Git에 포함하지 않습니다.

```sh
flutter build apk --debug --target-platform android-x64
```

빌드 결과를 `build/pc/haru-jogak-pc.apk`로 복사한 뒤 실행 버튼을 사용합니다. 다른 PC에서 실행하려면 동일한 구조로 도구·가상폰·APK를 준비해야 합니다.
